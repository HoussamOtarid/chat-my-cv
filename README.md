## 🤔 **Why Chat My CV?**

Your resume tells your story, but static PDFs can't answer follow-up questions. **Chat My CV** lets visitors have natural conversations with your professional background, making your resume interactive and memorable.

### **Perfect for:**
- 💼 **Freelancers & Consultants**: Let potential clients explore your expertise naturally
- 🎯 **Job Seekers**: Stand out with an innovative, conversational resume  
- 🌐 **Personal Websites**: Add an engaging "Ask me about my experience" feature
- ✨ **Tech Professionals**: Showcase your skills with cutting-edge technology

### **How it works:**
1. **Upload your resume** - PDF parsing extracts your professional information
2. **Configure AI** - Choose your preferred AI provider (OpenAI/Anthropic)  
3. **Share your link** - Visitors can chat with your resume 24/7
4. **Get discovered** - Stand out from traditional resume submissions

## 🚀 **Quick Start**

### **Prerequisites**

- **Node.js 22+** - [Download here](https://nodejs.org/)
- **pnpm** - Install with `npm install -g pnpm`
- **Supabase account** - [Sign up free](https://supabase.com/)
- **AI Provider** - Get API key from [OpenAI](https://openai.com/api/), [Anthropic](https://www.anthropic.com/api), or [Google AI](https://aistudio.google.com/app/apikey)

### **Installation**

**1. Clone and Install**
```bash
git clone <your-repo-url>
cd chat-my-cv
pnpm install
```

**2. Set up Supabase**
```bash
# Run the database migration (see supabase/README.md for details)
# Copy your Supabase project URL and anon key
```

**3. Configure Environment**
```bash
cp .env.local.example .env.local
```

Edit `.env.local` with your configuration:

### **Required Variables**
| Variable | Description | Example |
|----------|-------------|---------|
| `NEXT_PUBLIC_SUPABASE_URL` | Your Supabase project URL | `https://xyz.supabase.co` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anonymous key | `eyJ0eXAiOiJKV1Q...` |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service role key | `eyJ0eXAiOiJKV1Q...` |
| `ADMIN_EMAIL` | Your admin login email | `you@example.com` |
| `ADMIN_PASSWORD` | Your admin login password | `secure-password` |
| `ENCRYPTION_KEY` | 32-character encryption key | `your-32-char-encryption-key-here` |
| `IP_HASH_SALT` | Salt for IP address hashing | `random-salt-string` |
| `NEXTAUTH_SECRET` | Random secret for sessions | `your-secret-here` |

### **Optional Variables**
| Variable | Description | Default | Example |
|----------|-------------|---------|---------|
| `NEXT_PUBLIC_APP_URL` | Your app's public URL | `https://chatmycv.com` | `http://localhost:3000` |
| `NEXTAUTH_URL` | Authentication URL | Auto-detected | `http://localhost:3000` |
| `UPSTASH_REDIS_REST_URL` | Redis URL for rate limiting | None | `https://xyz.upstash.io` |
| `UPSTASH_REDIS_REST_TOKEN` | Redis token for rate limiting | None | `AstaLA...` |
| `MAX_FILE_SIZE` | Max resume file size in bytes | `10485760` (10MB) | `20971520` (20MB) |
| `NEXT_PUBLIC_SENTRY_DSN` | Sentry error monitoring | None | `https://xyz@sentry.io/123` |

> **Note**: AI API keys are configured securely through the admin panel, not as environment variables

**4. Run the Application**
```bash
pnpm dev
```

Visit [http://localhost:3000](http://localhost:3000) to see your chat resume!

### **🎯 First Steps**

1. **Visit `/admin/login`** - Sign in with your `ADMIN_EMAIL` and `ADMIN_PASSWORD`
2. **Configure AI** - Set up your preferred AI provider (OpenAI, Anthropic, Google AI, Azure OpenAI, or AWS Bedrock)
3. **Upload your resume** - PDF files are automatically parsed and encrypted
4. **Test the chat** - Visit the main page and try asking questions about your experience
5. **Share your link** - Your interactive resume is ready for visitors!

## 📁 **Project Structure**

This project follows **Next.js 15 App Router** conventions with a clean, organized structure:

- **`src/app/`** - Pages and API routes (admin panel, chat interface, authentication)
- **`src/components/`** - Reusable React components (UI, chat, admin, layout)  
- **`src/lib/`** - Core utilities (AI providers, database, auth, encryption)
- **`src/types/`** - TypeScript type definitions
- **`supabase/`** - Database migrations and policies
- **`public/`** - Static assets and images

> Built with modern Next.js patterns, shadcn/ui components, and TypeScript for maintainability
